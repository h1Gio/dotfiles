NixOS starter configuration for the user's Hyprland + NVIDIA laptop setup

CONTENTS
- configuration.nix
- modules/desktop.nix
- modules/gaming.nix
- modules/hardware.nix
- modules/networking.nix
- modules/packages.nix
- modules/users.nix
- modules/nvidia.nix (OPTIONAL; do not import until hardware/PCI IDs are confirmed)

IMPORTANT FIRST STEPS
1. Install NixOS using the graphical installer.
2. Keep the installer-generated /etc/nixos/hardware-configuration.nix. Do NOT replace it.
3. Back up the original /etc/nixos/configuration.nix.
4. Copy this configuration.nix and the modules directory into /etc/nixos.
5. Change users.users.gio in modules/users.nix if your Linux username is different.
6. Keep system.stateVersion = "26.05" only if the installed ISO/release is 26.05.
7. First test the configuration with:
     sudo nixos-rebuild test
   If it succeeds, activate it with:
     sudo nixos-rebuild switch

NVIDIA
The nvidia.nix file is intentionally not imported by default. It assumes an Intel iGPU + RTX 3050 Ti Mobile and PCI addresses 00:02.0 (Intel) and 01:00.0 (NVIDIA), based on the previously discussed laptop. If this is a different laptop, do not enable this file until the GPU model and PCI IDs have been checked.

To check hardware after installation:
  lspci -D | grep -E 'VGA|3D|Display'

If the detected GPU and addresses match the assumptions, add ./modules/nvidia.nix to the imports list in configuration.nix, then rebuild.

NOTES
- hardware-configuration.nix is generated by the NixOS installer and must remain machine-specific.
- The config uses iwd directly and disables NetworkManager, matching the stated preference.
- Hyprland-specific visual settings and existing dotfiles remain in ~/.config; these Nix files install and enable the software/services.
- Polkit authentication agent should be started from the Hyprland config, for example:
    exec-once = /run/current-system/sw/libexec/polkit-gnome-authentication-agent-1
  Check the installed path if that command does not exist on the chosen release.
- Some package attributes can change between nixpkgs revisions; if evaluation reports an unknown attribute, check https://search.nixos.org/packages for the installed release.
